# Bedrock data

Generated by `tools/bedrock-data/generate.py` for Minecraft: Java Edition 26.3 and the supported
Minecraft: Bedrock Edition releases (`src/version.rs`). Formats are described in the generator.

- `26_40/`: Bedrock 1.26.40-1.26.45 (network protocols 2168 and 2169)
- `26_50/`: Bedrock 1.26.50-1.26.52 (protocol 2193)
- `26_60/`: Bedrock 1.26.60-1.26.66 (protocol 2225)
- top level: biomes, sounds and entity identifiers, shared by all releases

  `stripped_biome_definitions.json`, `entity_identifiers.dat`) and the fallback tables of

  items for releases that lack them)

To update, check out both repositories at the new versions and run

    python3 tools/bedrock-data/generate.py <mappings> <Geyser> 26_40 26_50 26_60

with every palette version a supported release uses (Geyser's `ItemRegistryPopulator` lists
them per protocol). For a new Bedrock release add its palette version to the command, a
`Palette` in `src/data.rs` and a `Version` in `src/version.rs`, plus a layout method there for
each packet the release changed (compare the release's packet changes, e.g. in gophertunnel or
CloudburstMC Protocol). Drop the oldest release the same way when Geyser drops it.
